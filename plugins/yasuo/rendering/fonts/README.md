# Bundled fonts

`NotoSansSC.ttf` is the Google Noto Sans SC variable font. It keeps poster
rendering independent of system fonts and covers arbitrary Chinese nicknames and
message content.

## Update

The upstream source is the Google Fonts variable font `NotoSansSC[wght].ttf`.
Download it from the official Google Fonts repository and keep the filename
`NotoSansSC.ttf`. Do not subset it to static UI labels: user content is dynamic.
