# Pumpkin 浏览器连续执行与目标验收

本文保留旧 Obscura/MCP 执行链的演进记录。当前 Browser Profile 已改用受控 Playwright
locator inspect/action，删除 checkpoint、表单高层工具和元素引用；现状见
[统一 Agent Loop 与 Playwright Browser Profile](../20261109-pumpkin-playwright-browser/design.md)。

## 设计缘由

长网页任务可能耗尽旧的 36 步、40 次调用窗口，重新委派又会丢失页面。
字段填写成功与任务提交成功混淆，MCP 超时后的迟到响应可能串入下一请求，
过程截图也不能充当最终成果。原方案见
[已批准设计](../../../pumpkin-browser-optimization-design.md)。

## 入口和执行

`runtime.app.PumpkinRuntime` 装配 `BrowserCapabilityPlugin`、模型 Provider 和
`CapabilityServices`。Task Agent 按需加载 `browser-delegation` 后调用
`delegate_browser_task`；能力层检查 Task 的 scope/revision/授权，
从消息归档和任务纠正恢复用户原话，并读取 `TaskRuntime` 持有的单调截止时间。

`BrowserAgentRunner` 校验公网地址，创建 Worker run，初始化 Obscura MCP 并读取
白名单工具。同次委派每 12 个模型步骤通过 `_checkpoint` 保留原始目标、最新观察和
最近三次完整交互；继续使用同一页面，不释放租约、不重置预算、不调用额外摘要模型。
默认硬上限为 96 个模型步骤、120 次浏览器调用、720 秒，独立核验调用也计入步骤。
实际时限取浏览器上限与父任务剩余时间减 60 秒的较小值。

普通动作不能占用最后 8 步、10 次调用。执行分为 executing、finalizing 和 verifying：
收尾允许最多 2 次原目标点击，以完成用户已授权的最终交互；不重开导航或重新填写。
最后 3 步、4 次调用只允许观察、截图、PDF 和结束，保留提交后取证与独立目标验收。
小预算按总上限缩减预留，不扩充实际预算。工具批次内部逐项重新检查阶段、动作次数、
预留和不确定状态；参数拒绝不消耗收尾动作额度，已发送但失败的点击仍消耗额度。
结果不确定或点击额度耗尽时立即进入 verifying。`BrowserProgress` 用内存摘要比较动作后效果。
恢复只按完整动作与相关观察周期计数；截图、滚动、读取和未观察的动作不消耗额度。
未明确声明通道的表单动作默认比较完整字段状态；明确通道的动作以该通道核验。
有效效果变化清除计数，
引用、分页和无关页面文字变化不代表字段进展。不同字段页可以分别读取。
达到阈值提示重新观察，有界恢复失败则部分完成；摘要不持久化，也不能证明提交成功。
`browser_detect_forms` 的 `offset`、`limit` 和 `form_index` 由 Runtime 本地处理，
Worker 仍只接收无参数的表单检测。返回优先保留完整字段组计数、已填与未填数量和
状态摘要，再按输出预算返回完整字段对象；`next_offset`/`next_form_index` 指示后续页。
字段名列表过长时显式标记裁剪，计数和摘要仍覆盖完整表单。单个控件无法表示时
返回可感知的观测错误，允许改用交互元素引用。外层工具结果也保留 JSON 编码预算。
检查点保留最后观测的字段状态，即使修改动作已经使旧页面观察失效，也不丢失进度；
保留状态明确标为历史观察，不能代替修改后的重新确认。

`BrowserProgress` 将动作执行状态与观测效果分开记录，工具返回不等于目标效果已实现。
每次修改前记录有界 `BrowserActionReceipt`，后续同通道观察与修改前摘要比较：
`observed_change`、`no_observed_change`、`unknown` 或无基线时的 `unobservable`；
声明的 `expected_text` 在对应通道出现时为 `confirmed`。连续多项修改后的变化不能归因
到每一项动作。`expected_observation` 可指定预期通道，仅用于 Runtime 的证据关联；
无关通道不能重置该动作的恢复预算，也不进入 MCP 参数。表单状态变化和可比页面变化
重置计数及恢复额度；无效果周期跨不同参数累计，抑制换引用但没有效果的循环。

Worker 清单中的工具还需与受限参数契约兼容。`required_capabilities` 描述原请求严格
要求的交互方式与捕获范围；不满足时导航前返回 `BROWSER_CAPABILITY_UNSUPPORTED`。
引用点击不能替代严格要求的坐标点击，视口截图不能冒充整页截图。文本中的未结构化
要求仍由执行模型依据 capability manifest 判断，不通过关键词规则推断或放宽授权。

`BrowserArgumentError` 只表示发送前拒绝的模型参数错误，包含字段定位、选项值、
元素引用、等待文本和数值转换错误。运行时将错误码、具体原因和纠正提示作为工具结果
返回同一 Agent，保持当前页面版本、观察和视觉预览，不增加 MCP 调用次数。
参数失败次数在整个委派内累计，不因重新观察或换参数清零；达到
`stall_limit × recovery_limit` 后返回部分完成，防止无限纠正。
交互权限、公网 URL、Worker 和协议异常仍遵循原有拒绝或终止路径，不扩大工具边界。

## 证据和输出

工具结果包含观察身份、页面版本、动作状态和剩余额度。会改变页面状态的动作使旧观察
和预览失效，滚动使旧截图失效但保留字段观察；读取失败清除旧证据。
MCP `isError` 结果不能成为完成证据或产物。

截图由 Pillow 解码并缩小为 JPEG 视觉消息，即使不要求图片交付也可供执行模型观察；
只保留当前预览。可关闭视觉输入，解码和预览像素上限集中在 `BrowserConfig`。
产物字节不会代替视觉理解。

`finish_browser_task` 提出的是完成候选。`_finish` 首先检查证据来自当前页面观察，
截图或 PDF 对应当前版本，再独立调用同一 Provider 的 `report_browser_verification`。
核验输入仅包含原始目标、用户原话、最新观察、候选事实/链接及当前截图。
必须返回 passed 和可在观察中找到的引用；字段填完不证明提交成功。
语义核验依然依赖模型，不构成网站交易回执。

核验失败可在预算内再观察一次，仍不足则保留未核验原因并部分完成。
完成结果只返回最终版本的最新产物。能力层将其写入当前 Task revision 的候选 Artifact，
随后复用 Task 验收与 Outbox 交付；图片内容及文字可读性发送前再次核验。
失败和部分完成截图登记为 diagnostic，禁止结项或交付晋升；总超时保留诊断截图和实际计数。
所有返回的终态附带 `execution_report`：run_id、最后观察与版本、历史表单计数及
陈旧标记、最近动作回执和能力缺口。报告不把字段存在或页面变化声明为目标已完成，
父任务与幂等命中使用原运行报告；重开后的空白表单不能成为旧运行未提交的证据。

## 响应、幂等和清理

`BrowserWorker` 只持有一个待响应读取任务，匹配 JSON-RPC 版本和请求 ID，
跳过有限数量通知。请求超时不取消读取，迟到响应只消费原请求结果。
待响应未结束时不发送新请求；副作用超时将 run 标记为 uncertain_action，
后续修改永久封锁，可在原响应结束后继续观察，不自动重放提交。

能力层将模型提供的幂等键绑定 scope/task/revision 和目标、URL、交互与输出参数摘要。
另由 Runtime 计算逻辑操作键：公开交互按 scope/task/revision 的唯一交互操作去重，
不使用模型控制的 URL 或目标描述；只读任务按完整参数摘要去重。
参数摘要中的 URL 规范化仅统一协议/主机大小写、默认端口、空路径并移除片段，
保留路径与查询，不误删网站资源定位参数。
运行中逻辑操作一致的请求共享执行；同键参数冲突显式拒绝；公开交互改写目标或输出形式
或修改地址仍不能重开，新的用户交互目标需进入新任务版本；
多个页面的交互需在同一个完整委派目标内执行。
执行前持久化 in_progress 预留，终态缓存同时绑定逻辑操作键和模型键；中断后没有终态时
按结果不确定拒绝重放。仅无浏览器操作且可重试的失败释放预留。
硬终止后不能用换键续填，跨轮页面恢复未实现。

终态和取消回收进程组、读取任务、临时目录及租约；取消向上传播。
`BrowserWorkerClient` 为每个进程实例生成随机身份，能力层将 scope/task/revision
摘要作为 task_owner 传入租约。续期和取消同时检查 run_id、capability、实例与所有者；
旧请求无法回收或续期新运行。`BrowserAgentRunner` 在同次委派中最多等待 45 秒容量，
受父任务截止时间约束，等待不运行模型、不额外消耗父委派额度，超时返回明确未执行结果。
独立心跳任务每 5 秒发送续期，不与 MCP 请求串行；连接失效停止执行并保留结果待确认语义。
Worker 在心跳失联 30 秒后回收，900 秒硬租约不因续期延长。
创建租约期间取消时先接收已创建租约并释放，避免响应丢失留下无人清理的现场。
终态、取消和重复取消等待统一清理；Worker 清理任务共享且与请求取消隔离，
完成回收前不释放容量。客户端清理最多等待 5 秒，清理失败只记录错误码，
之后由心跳超时兜底。`BrowserCapabilityPlugin.close` 停止新委派并取消、等待活跃运行；
TaskRuntime 保留取消旧版本、等待执行退出后再调度新版本的顺序。
Mimi 根进程、Pumpkin 和 Worker 的 SIGTERM 进入正常关闭；Compose 的 init 负责子进程
回收，并设置停止宽限时间。
每次委派创建隔离现场，沿用公网校验、工具白名单和单 Worker 容量约束。
`pumpkin_browser` 单行日志记录模型/工具耗时、运行标识、步骤、调用次数、
批量字段数量和最后观测的字段计数；不记录 URL、页面正文、填答、状态摘要或工具参数。

## 实施边界与验证

### 2026-11-07 目标与效果闭环修订

动作恢复按完整的“动作 → 相关观察”周期计数。截图、滚动、无待确认动作的读取、
动作刚返回时均不消耗失败恢复额度；相关观察确认变化后重置额度。
动作声明的观察通道优先于页面是否包含表单，明确的预期文本由 Runtime 核对，
区分 confirmed、no_observed_change、unknown 和 unobservable。页面变化本身只表示
observed_change，不证明目标完成。导航隔离前后文档的观察基线。

委派可提供结构化 required_evidence，绑定本次运行的通道与精确文本；
全部条件必须在最新资源版本满足，再进入独立语义验收。缺少证据时保留部分完成。
原交互未完成或结果不确定时，后续只读运行仅提供自身观察与原交互报告；
父任务 completed 受原交互终态约束，不能用新页面晋升旧交互结果。
产物来源摘要绑定 run、页面版本和捕获身份，失败证据继续登记为 diagnostic。

本次没有引入跨轮 DOM 恢复、Worker 池、自动重建浏览器或网站专用成功文案。
尚未提供 Worker 级 document_epoch、逐项字段 effect 契约及真实模型成功率/延迟统计；
Runtime 导航隔离、页面版本、文本条件和实际再次观察承担当前证据校验。
控件类型或 checked 缺失时返回 unknown_field_count；DOM 统计仍不能证明应用接受状态。
长任务可能仍受模型判断和网站行为限制。

离线回归覆盖超过旧窗口的同页执行、预算预留、未提交误报、错误观察、迟到响应、
通知交错、视觉开关、父任务时间不足、取消、硬租约、幂等合并和参数冲突。
Artifact 回归覆盖诊断图不能交付、最终页面版本与逐图内容核验。
收尾回归覆盖步骤/调用边界的授权提交、提交后截图、只读拒绝、有限点击和不确定封锁；
委派回归覆盖换键/改写目标重开、只读目标区分、并发换键合并、进程中断预留与安全重试。
真实模型、视觉语义和多页站点行为需另外显式开启受控评测。
通用进度回归覆盖展开面板、筛选结果、异步加载、跨参数无效果动作、预期通道隔离、
模型故障及超时报告、能力不匹配和失败诊断产物缓存。
